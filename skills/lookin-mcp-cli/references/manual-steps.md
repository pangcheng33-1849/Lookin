# Manual Steps Checklist (Lookin Client)

CLI 只负责发起请求，以下步骤必须用户在 Lookin 客户端手工完成。

## A. 选中视图信息 / 样式
- 手工选中目标节点。
- 手工确认 Dashboard 已刷新到目标节点。

## B. 自然语言相关视图定位
- 手工在 Hierarchy/Preview 中选择候选节点。
- 手工右键执行 `add code info to item<id-description>`，把候选节点信息写入需求项。
- 手工复核 Requirement Code Info Board 中内容是否符合自然语言描述。

## C. 截图
- 手工切换被测 App 到目标视觉状态（例如弹层打开、列表滚动到目标区域）。
- 手工选中最终要截图的节点。
